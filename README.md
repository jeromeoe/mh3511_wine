# MH3511 Data Analysis with Computer - Project Work (15%)

**Due Date**: 12 April 2025, 23:59pm Sunday (Week 12)

## Project Requirements

- Download a relevant **dataset** from public websites or the R `datasets` package.
  - Must have **at least five variables** with a mix of different types.
- Set clear **objectives** (e.g., Estimation, Testing, Comparison).
- Conduct **exploratory data analysis** (plot graphs, check assumptions).
- Perform appropriate **statistical analyses**.
- Write a report of **15-17 pages** (excluding R code and appendix).

## Grading Rubric (15 Marks Total)

1. **Understanding of Dataset (2m)**: Clear description, variables, data types, and justification.
2. **Project Objectives (2m)**: Well-defined questions relevant to the dataset.
3. **Checking Assumptions (2m)**: Appropriate exploratory analysis and addressing assumptions.
4. **Statistical Analysis (4m)**: Correct choice/execution of tests, justification, and interpretation.
5. **Conclusions (2m)**: Interpretation of results finding in relation to objectives.
6. **Presentation of Information (2m)**: Well-structured tables, visualizations, clarity.
7. **Report Writing (1m)**: Logical organization, grammar, and formatting.
